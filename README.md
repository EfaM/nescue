# Nescue

**Nescue** ist ein Prototyp für eine Web-App für ein Uni-Projekt.

Das fiktive Unternehmen Shea Sepherd möchte das Meer von herrenlosen Geisternetzen befreien.
Daher soll eine Web-App die Möglichkeit bringen Netze (**n**et) zu retten (r**escue**) (= Nescue).

## Technologien
- Java 25 (Eclipse Temurin)
- Spring Boot 4 (Spring MVC, Thymeleaf, Spring Data JPA, Bean Validation)
- MySQL 8.4
- Maven
- GitHub Actions (CI)
